# Product Hunt Research Output Template

Use this template for the main markdown report.

## Scope

- research target
- research question
- why Product Hunt is useful for this analysis

## Method

- source collection method
- number of listings reviewed
- number of comment records reviewed
- notes on thread completeness

## Competitor Intelligence

- direct competitors
- indirect competitors
- substitutes
- adjacent tools

## Benchmarking Snapshot

- listing metrics
- short interpretation

## Positioning Research

- strongest positioning frames
- where the target product fits

## Customer Language

- repeated phrases
- key quotes
- interpretation

## Feature Discovery

- repeated feature bundles
- expected capabilities
- gaps or whitespace

## Audience and Segment Research

- who each product appears to target
- best-fit audience for the target product

## Pricing and Packaging

- visible pricing or package signals
- friction signals

## Go-To-Market Research

- launch-copy patterns
- fast-value patterns
- common structure

## Trend Tracking

- recurring themes over time
- category movement visible in this channel

## Comments Analysis

### Dataset summary

- listing count
- comment count
- corpus file links

### Creator intros

- creator language
- creator ideas
- strong examples

### User comments

- exact pros language
- exact cons language
- exact requests and open questions

## Synthesis for the Target Product

- core insight
- strongest narrative
- strongest differentiation
